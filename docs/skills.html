    Soft Skills

    • Communication

      • Explanation: Communication is an essential skill in computer science because modern software engineering is a collaborative, team-driven discipline rather than a solitary task. Code is written for human teammates to read and maintain, requiring clear documentation, meaningful commit messages, and constructive code reviews to ensure projects remain scalable and error-free. Furthermore, computer scientists must act as translators between technical systems and non-technical stakeholders—listening to client needs, articulating trade-offs, and explaining complex logic in accessible terms. Whether coordinating in daily Agile stand-ups, collaborating on remote teams via platforms like GitHub, or explaining a technical roadblock to debug an issue, strong written and verbal communication ensures that complex software systems are built efficiently, accurately, and safely.

      Context: I applied my communication, teamwork, and user interface design skills during a group project where our six-person team developed a comprehensive system proposal for SwiftChat to replace their manual processes with a scalable, automated collaboration platform. Serving as the UI Designer alongside a co-designer, I created the administration and employee views, prioritizing intuitive navigation, familiar layout standards, and seamless usability so users of any technical skill level could manage workspaces effortlessly. Beyond my primary design responsibilities, I actively drove team collaboration by maintaining continuous dialogue with my partner, reviewing and proofreading other team members' technical sections, participating in group discussions, and helping navigate communication challenges during mid-project holiday breaks. My proactive engagement and attention to detail ensured consistent quality across the final proposal while delivering an accessible, user-focused solution for the client

      Evidence: ISYS10242 System Analysis & Design (Mid 2.1)
