Technical Skills

  • Programming Languages: Python, C++,

    • Explanation: C++ and Python are essential skills because together they give you complete mastery over both ends of the software spectrum: low-level hardware performance and high-level rapid development. C++ gives you direct control over memory and system architecture, proving you understand how software interacts with hardware under the hood, which is critical for performance-driven fields like game engine development, robotics, and digital device engineering. On the other hand, Python’s clean syntax and massive library ecosystem make it the industry standard for rapid prototyping, cybersecurity scripting, automation, and artificial intelligence. Having both languages in your toolkit demonstrates to employers that you can not only engineer fast, memory-efficient core systems, but also quickly build, automate, and deploy modern applications on top of them..

    Context: I applied my programming skills by engineering two practical, object-oriented applications in Python and C++. For my Python project, I built a modular bus ticket command-line application that processes catalog data using custom TopUp classes and methods. It utilizes file handling with Python’s csv module (DictReader and DictWriter) alongside robust try/except exception handling to safely parse, filter, and write transaction records. I implemented dynamic data management using lists of dictionaries, sets for deduplication, list comprehensions, and control loops to keep the interactive user interface running smoothly. For my C++ project, I developed an advanced airport management and booking system using custom Structs (Airport and Booking) and dynamic vectors. To ensure high efficiency and prevent memory overhead when processing large datasets, I used constant references (const vector&) and raw pointers with nullptr checks for safe memory addressing. This application features complex mathematical distance calculations using the Haversine formula (sin, cos, atan2, stod), interactive input validation using cin.clear() and cin.ignore(), and a fully modular file structure split cleanly across headers and implementation files (.h and .cpp).

    Evidence: COMP10121: Foundations of Computer Programming 2025(Mid 2.1) COMP10111: Academic & Professional Dev 202526 Half Year (Mid 1st)

    Soft Skills

    • Communication

      • Explanation: Communication is an essential skill in computer science because modern software engineering is a collaborative, team-driven discipline rather than a solitary task. Code is written for human teammates to read and maintain, requiring clear documentation, meaningful commit messages, and constructive code reviews to ensure projects remain scalable and error-free. Furthermore, computer scientists must act as translators between technical systems and non-technical stakeholders—listening to client needs, articulating trade-offs, and explaining complex logic in accessible terms. Whether coordinating in daily Agile stand-ups, collaborating on remote teams via platforms like GitHub, or explaining a technical roadblock to debug an issue, strong written and verbal communication ensures that complex software systems are built efficiently, accurately, and safely.

      Context: I applied my communication, teamwork, and user interface design skills during a group project where our six-person team developed a comprehensive system proposal for SwiftChat to replace their manual processes with a scalable, automated collaboration platform. Serving as the UI Designer alongside a co-designer, I created the administration and employee views, prioritizing intuitive navigation, familiar layout standards, and seamless usability so users of any technical skill level could manage workspaces effortlessly. Beyond my primary design responsibilities, I actively drove team collaboration by maintaining continuous dialogue with my partner, reviewing and proofreading other team members' technical sections, participating in group discussions, and helping navigate communication challenges during mid-project holiday breaks. My proactive engagement and attention to detail ensured consistent quality across the final proposal while delivering an accessible, user-focused solution for the client

      Evidence: ISYS10242 System Analysis & Design (Mid 2.1)
